# robot-client

Godot 4 + C# клиент онлайн-игры про роботов в общем городе, собранном из открытых данных OpenStreetMap (OSM).

## Статус

**Bootstrap-этап.** Репозиторий пуст: зафиксирована архитектура клиента (Godot 4 + C#, камеры FPS/third-person, prediction/interpolation, навигация) и план этапов. Игровой код ещё не написан.

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) — архитектура клиента и план этапов.

## Стек

- Godot 4 (Mono / .NET)
- C# (.NET 8)
- WebSocket для связи с сервером (протокол v1, см. репозиторий robot-srv)

## Ассеты

Игровые ассеты (модели `.glb`/`.fbx`, текстуры, аудио) и OSM-дампы **не хранятся в репозитории**. Они поставляются из внешнего источника (репозиторий ассетов / CDN). Подробности — в политике ассетов (ARCHITECTURE.md) и `.gitignore`.

## Запуск

Клиент ещё не реализован. Инструкция появится после этапа «каркас проекта» (см. план этапов в ARCHITECTURE.md).
